HAND CHECK: 200 REVOLUTIONARY WAR WIDOW PENSION FILES
======================================================

What's in this folder
---------------------
  Hand_Check_200.xlsx   The workbook to fill in. Start on its "Instructions" tab.
  pdfs/                 The 200 transcriptions (PDFs from revwarapps.org), one per row
                        of the workbook.
  README.txt            This file.

How to start
------------
1. Keep the workbook and the pdfs folder together in the same place, so the
   "Open PDF" links in the workbook can find the files.
2. Open Hand_Check_200.xlsx in Excel (or Numbers / LibreOffice) and read the
   "Instructions" and "Label definitions" tabs first.
3. Work down the "Checking" tab, filling in only the yellow columns.

If you are using Google Sheets
------------------------------
Google Sheets can't open the PDFs on your computer from the "Open PDF" links.
Use the "Online copy" links instead (same files, on revwarapps.org), or open
the PDF from the pdfs folder by its file name.

When you're done
----------------
Save and send back Hand_Check_200.xlsx. Please don't rename the file or
reorder, add or delete rows.

Thank you!
